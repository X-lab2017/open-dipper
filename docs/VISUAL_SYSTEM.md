# OpenDipper × X-lab AI 视觉体系 v1.3

日期：2026-10-26。当前视觉源、颜色表与扩展方法见 [design/README.md](../design/README.md)。

已接受版本及源文件指纹见 [Atlas 1.3.0 基线记录](../design/baselines/atlas-1.3.0.md)；新模块使用[可复用设计模板](templates/OBSERVATORY_MODULE.md)。历史基线固定到实现提交，当前规范可随明确评审继续演进。

## 1. 品牌归属与官方素材

- 实验室母品牌：X-lab AI；产品名称：OpenDipper；说明：AI & OPEN SOURCE INTELLIGENCE / 全球 AI 与开源情报站。
- 官方标志来自 `X-lab2017/xlab-ai-brand`，锁定版本 `373d61f0d6e334f0b85af0dd5d8ef9b9095bcc37`。六个 SVG 原样保存于 `public/brand/`，来源路径和 Git blob SHA 记录在 `provenance.json`，测试验证字节一致。
- 观测站导航使用 Compact Wordmark，紧凑展示，约 64px；随屏幕等比调整，与产品字标的视觉高度协调。OpenDipper 简化图标用作 favicon。规范页的品牌展示可以更大，横版建议宽度至少 320px。
- ColorDark 用于深底，ColorLight 用于浅底。使用 `xlabLogo()` 自动提供对应版本；保留原始 X 负形、AI 右上标与内置安全区。禁止重绘、变形、加描边、换色、阴影或裁切。
- 产品名称与品牌之间使用细分隔线；北斗七星为产品辅助图形，不替代母品牌。
- 原始素材未授予通用开源许可。上游 `NOTICE.md` 原文随资源分发，下载本包不产生新的品牌、商标或再授权权利。实验室以本项目展示品牌的使用请求来自本次项目授权。

## 2. 视觉语言

界面使用蓝灰表面与青蓝交互强调色，项目影响力改为蓝绿色阶。品牌原色与官方素材保持原样。浅色和深色分别定义文字、底图、实体与气泡颜色，不通过透明度反转主题。普通文字和状态文字在规定表面的对比度目标至少 4.5:1；这不等于全站无障碍认证。

地图与图例共用 `src/design/scales.ts`：区域指标按 log1p 归一化，顺序色阶亮度单调；缺失值保留独立灰色。资产以气泡面积表示数量，实体采用圆形与环状纹理。选择状态使用统一交互色，不把图层颜色大面积铺在控件上。

## 3. 布局、地图与动态

桌面默认一屏。顶部五项总体统计、中间地图/地球、下方生态脉动；左右栏等宽。右侧以标签页切换当前观察，项目与资产优先前十排行，资讯保留新闻/活动切换。两屏增加完整清单与快讯；手机自然纵向布局并保留图层/地图/概览入口。

地图北向上，默认 10° E / 36° N，兼顾美国与中国；复位和 Home 使用同一相机定义。地球保留光照、点阵、大气与轻量外环扫光。地理悬停只描边实际地域，动态脉冲不产生虚构流向连线。地图全屏有常驻返回和 Esc；定位实体保持地图/地球模式。

减少动态时不自动旋转或播放模拟；不可见时停止推进。颜色变更不改变数据、排序或统计归属。动态图表保留简短模拟标识，完整口径集中在来源与指标说明。

## 4. 复用与验证

维护 `design/tokens.json`，运行 `npm run design:build` 生成 CSS、Canvas palette 和公开资源；不要手改生成文件。`src/design/components.css` 维护交互状态，布局由页面样式负责。视觉包仍使用原稳定下载 URL，包内版本为 1.3.0。

`npm run design:check` 验证品牌文件、文字与状态颜色；`npm run test:atlas` 验证明暗色阶、图例一致性、可选单选、气泡、相机与模拟边界。发布前检查两种主题的地图/地球、键盘、缩放、复位、全屏返回、标签与响应式。见 [工作台契约](ATLAS_WORKSPACE.md) 和 [发布计划](plans/atlas-release-v9.md)。
