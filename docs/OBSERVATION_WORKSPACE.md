## 视角与图层

左侧按开发者、组织、代码项目、模型、数据集、基础设施组织选择。规模和贡献属于开发者，影响力属于项目。地图、地球、快讯保持共用筛选；视角切换保留相机，重置为 7 天、全部地区，组合一个指标底图与多类事件叠加。手工调整主图层或事件筛选后显示“自定义组合”；此版本没有用户自定义组合的云端保存。

| 快捷视角 | 指标底图 | 事件组合 | 右侧重点 |
| --- | --- | --- | --- |
| 全球总览 | 开发者规模 | 全部 | 开发者、地域 |
| 开发者 | 开发者贡献 | 发布、社区、安全 | 仓库、资讯 |
| 企业 | 项目影响力 | 发布、安全、研究 | 组织、仓库 |
| 研究者 | 模型发布组织样本 | 研究、发布 | 模型、数据集 |
| 政策制定者 | 开发者规模 | 政策、基金会、研究 | 地域、组织 |
| 基金会 | Apache 关联贡献者 | 基金会、社区、安全 | 组织、资讯 |

组织关联贡献者不是总部位置；机构位置与数据中心显示待接入，无推测坐标。模型、数据集可切换仓库数／下载量，位置表示发布组织地域，不是训练、部署、数据来源地。新闻实践共用事件结构；实践须有 `practice` 标签。

## 八类总览的不同口径

全球开发者、模型仓库和数据集总量继续使用 [DATA_EVIDENCE.md](DATA_EVIDENCE.md) 的独立快照。239 地域为三个原始地域榜编码并集，不是国家数量，也不保证每个指标都覆盖。

组织索引：OpenDigger `5c2ffc4f5b3dd37ebcb20514c7abfee6853bd830` 的 5,777 个标签 YAML，508 个组织类型标签：企业 405、高校／科研 24、基金会 34、社区 42、公共机构 3。可含下属机构与重叠标签，不宣称是 508 个独立法人。显式仓库身份以平台名和仓库 ID 去重得到 13,019；没有递归获取组织下所有仓库。月度指标样本仍为 20 个。

AI 地域样本：GOSD `c51e3441361407b68f10b339d97eff288319b503` 的 `preview/content/gosm/supply-observation.json`。826 个发布组织账号，73,088 个模型仓库、12,502 个数据集。两类各 63 条地域记录，52 条有关联组织；其余 11 条作为缺失值，不用零填充。数据集沿用模型发布组织名单，不是全量数据集发布者。地域观察期未披露，不能借用平台总量的 2026-10-16 日期。列表可保留没有地图锚点的数据。

数据中心目前没有设施来源，显示 —；新闻为已发布、去重、非模拟事件数，随刷新更新。模拟内容不计入以上总览。

## 可复现数据链

- `data/reference/labeled-organizations.json`：固定来源、全部组织标签路径与哈希、仓库身份集合哈希；可用 `scripts/extract-label-coverage.py` 从固定提交重建（手动工具依赖 PyYAML）。
- `data/reference/gosd-geography.json`：原始选定字段、固定提交／blob SHA、各自时间与样本说明。
- `scripts/build-observation.mjs`：离线校验、地图锚点关联、缺失值转换，生成 `public/data/observation.json`。
- `src/observatory/workspace.ts`：视角注册表、可选快照验证、地图适配；`workspace-view.ts`／`workspace.css`：展示。
- `npm run observation:build` 重建；`npm run observation:check` 检查生成物及语义。浏览器测试纳入 `npm run test:observatory:ui`。

旧控制器中的可选快照失败会保留独立可用的数据；当前 Atlas 将该文件列为启动必需项，请以 [当前加载边界](DATA_CONTRACTS.md) 为准，不能沿用旧界面的降级保证。资产与标签保留各自来源条款，未赋予全仓库统一许可。

## 动态、来源和地域

事件沿用后台目标每 30 分钟采集、前端每 5 分钟检查部署快照。界面展示正在检查／最近成功检查／失败保留、实际新增事件提示；不滚动伪造总量，不宣称 WebSocket 实时流。新事件通过短暂高亮提示，减少动态效果偏好禁用动画。弹窗打开时收到快照，关闭后呈现，避免打断阅读。

重复的来源品牌从主要布局移至“数据与来源”。卡片保留必要年份、样本、待接入标记，地图详情保留可追溯来源与范围。

台湾是中国的一部分。共用显示函数将 TW／TWN／CN-TW 显示为中国台湾（英文 Taiwan, China）；中国范围包含该地域事件，地图／地球选择高亮采用中国分组。历史全景、地域列表、选择浮层及事件地点共用显示规则。原始编码和数值保留，不把政治显示分组当成可加总的统计依据。
