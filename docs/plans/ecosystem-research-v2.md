# Ecosystem discovery and research — review 1.5.0

Status: private review completed, 2026-10-26; superseded for release tracking by [the 1.5.1 public release plan](ecosystem-public-release.md). AI-assisted implementation by Codex. Builds on the 1.4.0 private review; the accepted public map/radar baseline remains 1.3.2.

## Outcome

Find projects for a concrete task, explain their ecosystem relationships, keep a small shortlist, compare evidence and take away a reproducible project report. Preserve the visual impact of the galaxy while making exploration useful.

## Scope

- Task-led discovery, weighted name/topic/language search, explainable matches, language filtering, same-domain peers and recorded-neighborhood focus.
- Up to three shortlisted entities, comparable metric rows, recorded connection paths without invented cross-network links.
- Project research dossier: identity, scope, graph metrics, known license and published facts from exact radar URL matches, dated monthly samples, recorded relationships, peers, exact-repository published events, verification gaps and next steps. Read no simulated radar assessments.
- Download Markdown, self-contained printable HTML and JSON. Generated time is not observation time. No claim of live web research, security audit or benchmark evaluation.
- Observatory-style circular framing, brighter landmark stars, clear selection/hover and relationship traces; paired themes, reduced-motion, responsive layout and source-preserving coordinates.
- Preserve the review Site audience. The private 1.5.0 publication is recorded below; the subsequently authorized public 1.5.1 release is tracked in [the public-release record](ecosystem-public-release.md).

## Validation

Data/model/report tests must cover exact URL identities, no inferred paths, no cross-source metric ranking, missing values, source clocks, export escaping and independent report results under UI filters. Browser checks: task/search → selection → shortlist → comparison/path → report/export; themes, expansion/return, mobile and other module navigation. Record only actual results below.
