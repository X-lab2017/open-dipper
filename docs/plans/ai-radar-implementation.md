## Roles and isolation

Codex owns application, integration, validation and publication. A bounded asset task handles product brand files/generator only; a bounded research task provides source facts in scratch without editing runtime files. The Site workflow explicitly delegates bounded asset/research work. No third-party application code or radar artwork is copied.

## Acceptance

- A visitor can explain the radar's purpose, switch software/models-data, choose a task, inspect a real entity and its source, compare at most three like entities, follow locally and export useful next steps.
- Demonstration advice is marked in the chart, details, comparisons and exports, with an off switch; hiding demos never manufactures reviewed placements or hides real source facts.
- Missing data stays unknown; measured windows remain attached. Unavailable radar data does not break the atlas.
- Keyboard, touch, language/theme, one/two screens and fullscreen return work. No paid service, cloud synchronization or new live ingestion is implied.
- Reusable logo variants are updated together, visually checked and included in the existing brand package.
