# 1.15.1 · 五模块联动收尾

日期：2026-10-27。维护者要求保持五模块结构，解决切换时导航跳动，精简重复入口并发布 Pages。本次为 AI 辅助工程实现；部署与验收证据记录于对应 PR / Actions，不以本文件作为部署成功证明。

## 原因与修改

- 原工具栏随模块增加/删除布局切换和来源按钮，其宽度变化参与导航居中计算。现在同宽上下文槽承载两类工具，全屏文案也使用固定宽度。
- 五个主导航共用同一布局；>1100px 桌面三列，≤1100px 独立导航行并可横向滚动。首轮浏览器回归发现新旧断点不一致会引起中等屏宽横向溢出，现已统一断点并保留严格检查。重绘保留导航滚动；当前模块按钮有稳定 ID 和 `aria-current`。
- 切换新模块清除文档级滚动并将焦点放回当前导航；重复点击当前模块保留阅读位置，避免重建工作区。
- 共建页底部删除已经在首屏/参与区提供的 GitHub 与贡献指南重复链接；保留 Agent、路线、许可、安全等信息披露。旧入口的“开源生态”更新为“开源星系”，关注提示改用准确的项目详情描述。

- 完整矩阵额外发现 390px 英文雷达的网格最小内容宽度撑出视口；改为可收缩轨道与可换行视角控件，保留全部信息。

## 范围与验证

不更改五模块结构、数据快照、排名、图层、报告内容、存储键或 DSH 服务状态。来源/模拟/权利披露保留。

执行 `npm run typecheck`、`npm test`、`npm run build`；浏览器验收由现有 GitHub Actions 在 `/open-dipper/` 子路径执行。新增 `tests/navigation-ui.mjs` 检查 1366/1024/768/390px、中英与明暗下五模块按钮坐标（容差 1px）、横向溢出、重复点击、滚动复位、键盘焦点及来源弹窗。截图产物由 CI 保存，不提交源码。

所有检查与最终发布结果以关联 PR 的逐项回执为准。当前环境本地受管浏览器不可用，不能将本地构建声称为人工线上浏览验收。
