# OpenDipper 1.6.0 · 从全局观测到下一步探索

发布日期：2026-10-27（Asia/Shanghai）。这是已上线应用的里程碑记录，应用版本 1.6.0、视觉 tokens 1.4.0；固定地图／雷达参考仍是 1.3.2。本文不宣称创建了 Git tag 或 GitHub Release。

[体验平台](https://www.x-lab.info/open-dipper/) · [首次试用反馈 #35](https://github.com/X-lab2017/open-dipper/issues/35) · [当前缺口](../STATUS.md) · [宣传短片与复现](../../media/promo/README.md)

## 这一版带来了什么

- 全球地图按主要陆地区域居中；左栏面、泡、点使用一致的图形尺度和对齐。
- 默认展示活跃开发者，随后依次是企业、标杆项目、模型资产、会议与活动；“环球巡航”在五个面板间串联地图与立体地球，支持暂停、切站、结束与恢复原视角。
- 明暗主题共享文字、数据和状态语义，保持紧凑三栏、五项概览、完整排行和生态脉动；Logo 更紧凑。导航统一为“开源星系”。
- AI 雷达继续提供任务发现、来源、同类对比与试用清单；开源星系提供双网络、研究清单、记录路径和 Markdown / HTML / JSON 报告。

## 人与 Agent 如何参与

先完成一次真实任务，再到 [#35](https://github.com/X-lab2017/open-dipper/issues/35) 写“想做什么 → 实际发生什么 → 卡在哪里”，附模块、主题、尺寸或来源链接即可。独立缺陷先去重再建 issue；数据纠错使用[来源纠错表单](https://github.com/X-lab2017/open-dipper/issues/new?template=data_correction.yml)。

工程参与者从 [AGENTS.md](../../AGENTS.md) → [STATUS](../STATUS.md) → [任务索引](../CONTEXT.json) 开始，只读取相应契约。历史计划和图片用于追溯，不是等待恢复的任务；文档与宣传素材的源文件、时间和检查方法均有记录。[贡献指南](../../CONTRIBUTING.zh-CN.md)包含实际测试、授权边界与交接方式。

维护者提供方向、评审反馈和发布授权；Codex 作为 AI 助手参与设计、实现、测试、截图、文档整理与短片制作，并进行自审。没有把 AI 自审表述成人工验收，也不公开私人聊天或内部提示。Hallmark 的设计原则与 Amicro 的动画参考均是参考资料，不赋予额外操作授权；具体来源见[视觉过程](../plans/visual-workbench-review.md)与[短片说明](../../media/promo/README.md)。
